# ToolMint

ToolMint is a lightweight collection of browser-based utility tools built for developers, students, and anyone who needs a quick productivity boost.

![ToolMint homepage screenshot](assets/homepage.png)

## What you can do here

ToolMint brings together handy tools for text, data, images, and developer workflows, including:

- Text utilities: Base64 encoder/decoder, HTML encoder/decoder, case converter, slug generator, and word counter
- Data helpers: JSON formatter, JSON-to-CSV, CSV-to-JSON, and markdown-to-HTML
- Image utilities: image resizer, image-to-base64 conversion, and QR code generation
- Developer tools: regex tester, JWT decoder, SHA256 generator, timestamp converter, and password generator
- Calculators: age calculator, EMI calculator, percentage calculator, and unit converter

## Why ToolMint?

This site is designed to be easy to use on any modern browser. It provides simple, fast, and approachable tools for one-off tasks or everyday workflows without needing to install anything.
