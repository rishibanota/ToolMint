How to use

  1. Enter original dimensions (width x height) or pick a preset ratio (16:9, 4:3, 1:1).
  2. Enter a new target width or height.
  3. Click Calculate Dimensions to find the missing dimension.

Frequently asked questions

What common ratios are supported?

Popular presets like 16:9 (HD video), 4:3, 1:1 (square), 21:9 (ultrawide), and 9:16 (vertical story) are supported.

Does it simplify custom ratios?

Yes, entering any width and height computes the simplified integer ratio (e.g. 1920x1080 -> 16:9).
