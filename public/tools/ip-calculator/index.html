Frequently asked questions

What is CIDR notation?

CIDR (Classless Inter-Domain Routing) specifies an IP address and its associated network mask length (e.g., /24).

How many hosts are usable in a /24 subnet?

A /24 subnet has 256 total IP addresses and 254 usable host addresses.
