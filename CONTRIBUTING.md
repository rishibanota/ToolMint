# Contributing to ToolMint

First off, thank you for considering contributing to ToolMint! It's people like you that make ToolMint a great tool for developers and students.

## Where do I go from here?

If you've noticed a bug or have a feature request, make sure to check our [Issues](https://github.com/rishibanota/ToolMint/issues) to see if someone else has already opened one. If not, feel free to open a new issue.

## How to contribute

1. Fork the repo and create your branch from `main`.
2. Make sure your code adheres to the existing style. ToolMint is a lightweight collection of browser-based utility tools.
3. If you add a new tool or feature, please ensure it works well on modern browsers.
4. Issue a pull request!

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
